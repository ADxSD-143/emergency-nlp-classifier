# Emergency NLP Classifier

An NLP learning project for classifying emergency reports by incident type.

## Learning progression

Raw Text → NLP EDA → Preprocessing → TF-IDF Baseline → Classical ML → Embeddings → Neural NLP → Transformers

## Initial classes

- Fire
- Flood
- Accident
- Medical Emergency
- Crime
- Earthquake

## Project philosophy

This repository documents the learning journey, including theory, experiments, bottlenecks, errors, failed approaches, improvements, observations, and lessons learned.

TF-IDF is a baseline, not the final destination. Later stages will investigate semantic and contextual representations.
